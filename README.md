# Fuze — C++ Builder

GUI-склейщик двух `.exe` в один исполняемый файл. Оба файла шифруются AES-256-CBC, зашиваются в C++ обёртку в виде байтовых массивов и компилируются в единый `.exe`, который при запуске расшифровывает оба и дропает по выбранному пути.

## Что делает

- выбор двух `.exe`-файлов
- выбор пути дропа для каждого независимо: `%Temp%`, `%AppData%`, рядом с самим `.exe`, `C:\Users\Public`
- выбор иконки — `.ico` `.png` и тп напрямую или извлечение из любого PE-файла
- шифрование AES-256-CBC с рандомным ключом и IV на каждую сборку
- генерация C++-стаба и компиляция в один `.exe`

## Что использует

**Python:**
- `customtkinter` — GUI
- `cryptography` — AES-256-CBC шифрование

**Системные бинарники:**
- `g++` (MinGW-w64) — компиляция C++
- `windres` (идёт в комплекте с MinGW-w64) — компиляция ресурсов иконки

## Установка
### 1. Python 3.9+
качаем питон, например отсюда - https://www.python.org/ftp/python/3.11.0/python-3.11.0-amd64.exe , при установке ввыбираем обе галочки.

### 2. Python-зависимости

```bash
pip install customtkinter cryptography
```

### 3. MinGW-w64

Качаем MinGW отсюда и распаковываем:
https://github.com/brechtsanders/winlibs_mingw/releases/download/15.2.0posix-13.0.0-ucrt-r5/winlibs-x86_64-posix-seh-gcc-15.2.0-mingw-w64ucrt-13.0.0-r5.zip

### 4. 
Запускаем файл:
```bash
python fuze.py
```
указываем в открывшемся гуи путь к MinGW/bin/
выбираем .exe файлы, пути сохранения, иконку, жмем скомпилировать.
На выходе — `file.exe` рядом со скриптом.
